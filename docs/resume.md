# 简历

## 实习经历

**2026.05 — 至今　　　　　　　　上海任意门科技有限公司（Soul）　　　　　　　　服务端开发实习生**

**实习背景**：负责语音匹配服务（商业化 reco 链路）的后端迭代与治理：并发问题修复、在线链路性能优化、Kafka 消费链路改造，并开发实验策略取数 Agent（SQL 知识库 + RAG）。

**核心工作**：

- **定位卡等待弹窗推荐**：用卡用户等待匹配超阈值（Apollo 可配）时触发弹窗推荐以提升接通率——触发基于 Redis ZSet 延迟队列（score = 到期时间戳），消费以 Lua 原子弹出（ZRANGEBYSCORE + ZREM 单次往返）防多实例重复消费、按具体 member 删除规避同分误删；候选匹配经分布式锁互斥，原实现 setnx 与 expire 分离存在锁永久泄漏（进程崩溃后用户无法再被匹配），改造为 SET NX EX 原子加锁 + 释放校验锁归属；弹窗频控（发送/曝光双 key）由 reco 写、pipeline 前置读，实现主叫拦截与候选过滤；
- **免费男性延迟匹配 UCB 策略支撑**：负责策略的后端工程化——按付费等级分段的探索统计异步结算入 Redis Hash（支付/挂断回调触发，按 modelVersion + 分段分桶，进程内无锁原子累计），过期未结算任务定时批量清理，保证统计窗口不残留脏数据；选臂接口纯函数化（输入候选与统计、输出臂，策略可单测），冷启动探索与系数 α 均经实验参数下发；
- **可视化平台 Kafka 消费链路优化**：消费落库单条 INSERT 改批内合并 + 500 条/块批量写入，Hive 回写异步化；子批失败整批不 ack 触发重投（DuplicateKey 视为幂等成功），消除部分失败静默丢数——宁可 lag 堆积不丢数据；查询接口 N+1 改批量 IN、服务端轮询改事件触发；
- **实验策略 Agent 开发**：在 SQL 批量跑批平台（多线程跑批 + 异步飞书记录，端到端耗时降约 89%）之上构建取数 Agent，按自然语言需求生成实验取数 SQL 并直查内部 Hive 验证：
  - 双知识库：业务表知识库（表 DDL/字段口径/参考 SQL）摘要向量化按需检索；指标口径与查询规范库（指标公式/日期参数/实验参数格式/常见问法转述）作为常驻提示词不走检索，保证每次生成口径一致；
  - 质量评估：以真实历史取数需求 + 业务方核实的结果数据构建评测集（50 条）回归——业务需求准确率 90%、知识库外查询拒绝率 95%（宁拒不编造）；badcase 回流更新知识库，同类错误不二犯；
